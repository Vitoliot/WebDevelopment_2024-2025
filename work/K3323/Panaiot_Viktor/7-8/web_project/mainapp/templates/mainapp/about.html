О разработке

Общий замысел проекта

Данный проект создан для демонстрации минималистичного дизайна с использованием фреймворка Django на backend и Bootstrap на frontend. Мы постарались сочетать современный внешний вид, удобство навигации и адаптивную вёрстку, чтобы проект выглядел актуально на любом устройстве.

Стек технологий
  • Django: Python‑фреймворк для создания веб‑приложений, обеспечивающий удобную структуру и безопасность.
  • SQLite: Встроенная база данных для удобства разработки и тестирования. При необходимости легко заменить на PostgreSQL/MySQL.
  • Bootstrap: CSS‑фреймворк для быстрой и адаптивной вёрстки, здесь используется для оформления форм, кнопок, сетки, модалок и т. д.
  • JavaScript (Vanilla + Bootstrap): Используется для небольших интерактивных элементов, таких как тултипы, модальные окна, а также для интерактивной карты.
  • GitHub (опционально): система контроля версий для хранения кода и совместной разработки.
Цели и особенности структуры

Главная цель — показать, как организовать учебный проект на Django с использованием шаблонов, форм и базовых CRUD‑операций (в нашем случае через форму обратной связи). Проект легко расширять, например, добавив авторизацию, личные кабинеты пользователей, дополнительный функционал (API, веб‑сокеты и т.д.).

Мы применяем принцип «не усложнять там, где это не нужно», создавая минималистичную структуру: одно приложение mainapp, базовый шаблон base.html, несколько простых страниц и модель Feedback для хранения отзывов. В реальных проектах можно разбить логику на несколько приложений (например, users, posts, comments) в зависимости от задач.

Спасибо, что обратили внимание на наш проект! Если возникнут предложения или идеи по улучшению, вы всегда можете оставить сообщение на странице «Обратная связь».
